# ハードウェア詳細メモ

READMEに載せるには細かいが、失うと再調査が必要になる情報の置き場。

## Livox Mid-360(VLP-16天面に搭載、2026-08-04)

- **取付オフセット**: チルト軸(=VLP-16光学中心)から**+81.0mm**上に
  Mid-360の点群原点がある。内訳: VLP-16原点→天面 34.0mm
  (全高71.7 − 原点高37.7、VLP-16マニュアルRevF §9.1)+ Mid-360底面→
  光学中心 47.0mm(Mid-360ユーザーマニュアル機械図面。IMU実装位置
  z=−44.12mmとの整合で確認)。天面直載せ前提、アダプタ板があれば加算。
- **座標系の向き**: Mid-360は+XがM12コネクタの**反対**方向。VLP-16と
  X軸を揃えるにはコネクタを後方に向けて取り付けること(現状yaw=0を仮定)。
- **ネットワーク**: 出荷時静的IP `192.168.1.1XX`(XX=S/N下2桁)。本機は
  `192.168.1.106`。ホストは既存の`192.168.1.100`のままでよい
  (`config/MID360_config.json`のhost_net_infoに記載。ポートは561XX系)。
  VLP-16(192.168.1.201)と同一サブネットなので**同じUSB-Etherにスイッチを
  介して両方接続可能**。
- **ドライバ**: livox_ros_driver2(Jazzy対応はv1.2.6以降。Dockerfileで
  master をビルド、`-DDISTRO_ROS=jazzy`必須)。PointCloud2で出すため
  `xfer_format:=0`でノードを直接起動(rviz向け。`msg_*launch.py`系の
  CustomMsgはFAST-LIO等用)。トピック: `/livox/lidar`(10Hz、~20k点/フレーム)、
  `/livox/imu`(ICM40609、200Hz)。
- **FOV**: 水平360°× 垂直−7°〜+52°。水平360°のため下向き掃引中も後方で
  天井が見える。測距 40m@10%反射率。
- **検証(2026-08-04)**: `verify_sweep.py`で全掃引範囲(出力軸±50°)を
  80秒間集計し、天井高さの推定が全チルト角ビンでstd 2.2cm(中央値3.13m)。
  TF補償が全方向で機能していることを確認。床側のばらつきは可視領域の
  変化(家具等)によるもの。

## RMD-X8 Pro(レガシーLK系ファームウェア)

- CAN ID `0x141`、1Mbps。V3系コマンド(0x42等)は不応答。
- 0x92/0xA4の角度は**ロータ角**(出力軸角 = /6.2)。0x92はDATA[1..7]の
  符号付き56bit LE、0.01deg/LSB。
- 多回転基準は電源断で失われるが、単回転エンコーダ(0x9C DATA[6..7]、
  65536/回転)は絶対値。水平のencoder値を記録しておけば±180°(ロータ)
  以内から水平を一意に復元できる。
- 0xA4の速度制限はソフト。25dps以下なら指令にほぼ一致、40dps以上では
  最大+60%超過する。
